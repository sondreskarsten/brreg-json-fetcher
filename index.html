BRREG annual accounts

Unofficial mirror maintained by sondreskarsten. Not operated, approved or endorsed by Brønnøysundregistrene. Inneholder data under NLOD 2.0 tilgjengeliggjort av Brønnøysundregistrene.

Download the monthly dataset

Every month all Norwegian AS and ASA entities with a filed annual account are fetched once and published as a data-YYYY-MM release. Use the finished dataset instead of calling the API for each company.

Look up one organisation

Enter an organisation number and select Fetch to see the parsed filings and download CSV. Opening a link never starts a lookup.

Looks up https://data.brreg.no/regnskapsregisteret/regnskap/{orgnr}. The browser tries a direct request first, then Jina Reader and AllOrigins if direct cross-origin access fails. Proxy providers can see the organisation number requested and the response. The route and response format are shown below. Jina Reader reformats the upstream response and may return XML instead of JSON. Its HTML processing can change XML field nesting, so use the monthly CSV or the original API response for structured analysis. This site has no server of its own.
