Finn regnskap

Nøkkeltall fra Regnskapsregisteret. Skriv inn organisasjonsnummeret for å sammenligne år og laste ned regnskapene som CSV.

Om datakilden og offentlige proxyer

Oppslaget forsøker BRREG direkte, deretter Jina Reader og AllOrigins. Proxytilbyderen kan se organisasjonsnummer og svar. Jina kan endre XML-feltnavn og nesting; dette markeres i visningen og nedlastingene. Ingen oppslag startes fra lenker.

Last ned månedsdatasettet

Every month all Norwegian AS and ASA entities with a filed annual account are fetched once and published as a data-YYYY-MM release. Use the finished dataset instead of calling the API for each company.
